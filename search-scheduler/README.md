# Datagram Search Scheduler

Node.js-скрипт, который **сам создаёт и пересоздаёт** задачи поиска Telegram-групп/каналов в Datagram, ротируя большой пул ключевых слов.

## Что делает

1. Берёт следующий батч ключевых слов из пула (`keywords.json`).
2. Создаёт задачу поиска через Datagram Public API (`POST /tasks`).
3. Сохраняет прогресс в `state.json` (курсор по пулу).
4. Через заданный интервал повторяет — берёт следующую порцию, и так по кругу.

## Структура

```
search-scheduler/
├── index.js            # основной скрипт (без внешних зависимостей, fetch из Node 18+)
├── keywords.json       # пул ключевых слов (30k+)
├── config.json         # настройки (API-ключ, интервал, размер батча, лимиты)
├── state.json          # прогресс ротации (создаётся автоматически)
├── results/            # сюда можно складывать выгрузки результатов
├── Dockerfile
├── docker-compose.yml
└── package.json
```

## Запуск

### Локально (Node 18+)

```bash
cd search-scheduler
node index.js --once     # один батч и выход
node index.js            # батч + планирование следующего запуска
```

### Docker

```bash
cd search-scheduler
docker compose up -d --build
```

## Настройки (config.json)

| Ключ | Описание | По умолчанию |
|---|---|---|
| `apiBaseUrl` | Базовый URL API | `https://api.datagram.info/api/public/v1` |
| `apiKey` | API-ключ (`dg_live_...`) — или env `DATAGRAM_API_KEY` | — |
| `batchSize` | Ключей на задачу (макс. 10) | `10` |
| `limitPerTask` | Целевое число каналов на задачу (10–5000) | `500` |
| `intervalMinutes` | Интервал между запусками | `60` |
| `maxConcurrent` | Лимит одновременных задач (по тарифу) | `1` |
| `dailyTokenBudget` | Дневной бюджет токенов (по тарифу) | `250` |

## Ограничения API Datagram (важно)

- `keywords`: 1–10 шт., каждый ≤ 100 символов.
- `limit`: 10–5000.
- Rate limit: **60 запросов/мин** на ключ (скрипт уважает `Retry-After`).
- **Дневной бюджет токенов** (Free = 250/день) — скрипт проверяет `GET /me` и пропускает запуск, если бюджет исчерпан.
- **Лимит одновременных задач** (Free = 1) — скрипт проверяет и пропускает, если занято.

## Пул ключевых слов

Сгенерирован программно: категории (спорт, авто, гейминг, бизнес, финансы, дейтинг, саморазвитие и т.д.) × страны (USA, UK, Ирландия, Канада, Австралия, Новая Зеландия, ЮАР) × города. Целевая аудитория — мужчины 21+, англоязычные. Крипта исключена.

## Статус API (важно)

Публичная спека описывает `/tasks` и `/me`, но на живом шлюзе (2026-09-10) эти эндпоинты отдают **404**. Реально отвечают только внутренние пути кабинета (`/api/v1/cabinet/me` → 401 с ключом). Перед боевым запуском подтвердить, что публичный API развёрнут, и поправить `apiBaseUrl`/пути в `index.js`.

## Правильный путь API (обновлено)

Реальный публичный API живёт на `https://api.datagram.info/api/public/v1/` (не `datagram.info/api/v1`). Эндпоинты:
- `POST /tasks` — запуск задачи
- `GET /tasks/{id}` — статус
- `GET /tasks/{id}/results` — результаты
- `GET /me` — тариф и лимиты

На момент проверки (2026-09-10) эти пути отвечают `401 Unauthorized` с `WWW-Authenticate: Bearer error="invalid_token"` — путь верный, но ключ не принимается. Нужно перевыпустить/проверить API-ключ в кабинете.
