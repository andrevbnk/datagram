# Datagram Search Scheduler

Node.js-скрипт, который **раз в день** (по умолчанию 13:00) запускает сессию поиска Telegram-групп/каналов в Datagram: создаёт задачи до исчерпания дневного бюджета токенов, автозагружает результаты и шлёт уведомления в Telegram.

## Модель работы

1. В заданное время (13:00) стартует сессия.
2. Берёт батч из 10 уникальных ключевых слов (без повторов).
3. Создаёт задачи (`type: auto` — валидатор включён).
4. Ждёт завершения, скачивает результаты в `results/`.
5. Повторяет, пока не кончится дневной бюджет токенов (20 000).
6. Ключи не повторяются; когда пул исчерпан — генерирует новые уникальные.

## Структура

```
search-scheduler/
├── index.js            # основной скрипт (без внешних зависимостей, Node 18+)
├── keywords.json       # базовый пул ключевых слов (30 132)
├── config.json         # настройки (время запуска, батч, лимиты)
├── state.json          # прогресс: курсор, использованные ключи, задачи
├── results/            # выгруженные результаты (<task_id>.json)
├── .env                # секреты (не коммитится)
├── .env.example
├── Dockerfile
├── docker-compose.yml
└── package.json
```

## Запуск

### Локально (Node 18+)

```bash
cd search-scheduler
cp .env.example .env   # заполни ключи
node index.js            # планировщик (ждёт 13:00)
node index.js --now      # запустить сессию немедленно (тест)
```

### Docker

```bash
cd search-scheduler
docker compose up -d --build
```

Контейнер запускает `crond`, который ежедневно в **13:00 (Europe/Berlin)** выполняет `node index.js --now`. Логи — `/var/log/scheduler.log` внутри контейнера (`docker compose logs scheduler`).

## Настройки (config.json)

| Ключ | Описание | По умолчанию |
|---|---|---|
| `apiBaseUrl` | Базовый URL API | `https://api.datagram.info/api/public/v1` |
| `batchSize` | Ключей на батч (макс. 10) | `10` |
| `limitPerTask` | Целевое число каналов на задачу | `500` |
| `runHour` / `runMinute` | Время ежедневного запуска | `13` / `0` |
| `timezone` | Часовой пояс | `Europe/Berlin` |
| `pollIntervalSeconds` | Интервал опроса статуса | `30` |
| `maxWaitMinutes` | Макс. ожидание завершения батча | `20` |

Секреты (`DATAGRAM_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`) — в `.env` или переменных окружения, **не в config.json**.

## Telegram-уведомления

Бот `@Datagram_tg_bot`. Уведомления: старт/конец сессии, создание батча, исчерпание бюджета, ошибки.

## Ограничения API Datagram

- `keywords`: 1–10 шт., ≤100 символов.
- `limit`: 10–5000.
- Rate limit: 60 запросов/мин (уважается `Retry-After`).
- Дневной бюджет токенов (professional = 20 000).
- Лимит одновременных задач (professional = 10).

## Реальный формат API (отличается от спеки)

- `POST /tasks` → **202** с `{"tasks": [{task_id, status}, ...]}` — каждое ключевое слово = отдельная задача.
- `GET /me`: `concurrent` содержит только `limit` (нет `active`).
- `GET /tasks/{id}/results` → `{task_id, items, cursor, has_more}`.

## ⚠️ Неподтверждённые возможности

- **AI Enricher** и **выбор канал/чат** — в публичном API нет параметров (только `type: auto`). Это опции UI дашборда. Уточнить у поддержки Datagram.
- **Возврат токенов** после завершения задач — по факту не наблюдается (`used_today` не уменьшается). Скрипт работает до исчерпания бюджета, не рассчитывая на возврат.
