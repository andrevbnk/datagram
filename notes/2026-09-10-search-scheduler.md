# Поиск Telegram-групп/каналов — задача и договорённости

Зафиксировано: 2026-09-10.

## Задача

Node.js-скрипт, который **сам создаёт и пересоздаёт** задачи поиска Telegram-групп/каналов в Datagram по нужной тематике.

## Требования

- **Целевая аудитория:** мужчины 21+.
- **Язык:** англоязычные группы (USA, Британия, Ирландия и другие англоязычные страны).
- **Крипта исключена** (по решению пользователя).
- **Большой пул ключевых слов** для этих стран.
- **Периодический запуск** — ротация по пулу: каждый запуск берёт следующую порцию ключей.

## Решения

- **Планировщик:** Docker / сервер с планировщиком (не node-cron внутри, не системный cron).
- **Ротация:** каждый запуск берёт следующий батч ключей из пула (курсор в `state.json`), по кругу.
- **Пул:** сгенерирован программно — категории × страны × города = **30 132 ключа**.
- **API:** Datagram Public API (`public-spec.yml`).

## Ограничения API (из спеки)

- `keywords`: 1–10 шт., ≤100 символов каждый.
- `limit`: 10–5000 (по умолчанию 500).
- Rate limit: 60 запросов/мин (уважать `Retry-After`).
- Дневной бюджет токенов (Free = 250/день).
- Лимит одновременных задач (Free = 1).

## Статус API (важно)

Публичная спека описывает `/tasks` и `/me`, но на живом шлюзе (2026-09-10) эти эндпоинты отдают **404**. Реально отвечают только внутренние пути кабинета (`/api/v1/cabinet/me` → 401 с ключом). Перед боевым запуском подтвердить, что публичный API развёрнут, и поправить `apiBaseUrl`/пути в `index.js`.

## Правильный путь API (обновлено)

Реальный публичный API живёт на `https://api.datagram.info/api/public/v1/` (не `datagram.info/api/v1`). Эндпоинты:
- `POST /tasks` — запуск задачи
- `GET /tasks/{id}` — статус
- `GET /tasks/{id}/results` — результаты
- `GET /me` — тариф и лимиты

На момент проверки (2026-09-10) эти пути отвечают `401 Unauthorized` с `WWW-Authenticate: Bearer error="invalid_token"` — путь верный, но ключ не принимается. Нужно перевыпустить/проверить API-ключ в кабинете.
