# Поиск Telegram-групп/каналов — задача и договорённости

Зафиксировано: 2026-09-10. Обновлено: 2026-09-11.

## Задача

Node.js-скрипт, который **раз в день** (13:00) запускает сессию поиска Telegram-групп/каналов в Datagram.

## Требования (финальные)

- **Целевая аудитория:** мужчины 21+, англоязычные (USA, UK, Ирландия и др.).
- **Крипта исключена.**
- **Расписание:** раз в день в 13:00.
- **Запуск до исчерпания токенов:** создавать задачи, пока не кончится дневной бюджет (20 000).
- **Валидатор:** включён (`type: auto`). **AI Enricher:** выключен (в публичном API не управляется).
- **Искать каналы и чаты** (в публичном API нет параметра выбора — уточнить у поддержки).
- **Ключи не повторяются**; при исчерпании пула — генерировать новые уникальные.

## Решения (2026-09-11)

- `type: auto` как есть (валидатор уже включён), про enricher/чаты — уточнить у поддержки Datagram.
- Запускать до исчерпания бюджета (20 000), **не рассчитывая на возврат токенов** (по факту `used_today` не уменьшается после завершения задач).
- Ключи: курсор по пулу + `usedKeywords` в state.json; при исчерпании — генерация `prefix + base` / `base + suffix`.

## Ограничения API (из спеки + реальность)

- `keywords`: 1–10 шт., ≤100 символов.
- `limit`: 10–5000.
- Rate limit: 60 запросов/мин.
- Дневной бюджет: professional = 20 000 токенов.
- Одновременных задач: professional = 10.

## Реальный формат API (отличается от спеки)

- `POST /tasks` → **202** с `{"tasks": [{task_id, status}, ...]}` — каждое ключевое слово = отдельная задача.
- `GET /me`: `concurrent` только `limit` (нет `active`).
- `GET /tasks/{id}/results` → `{task_id, items, cursor, has_more}`.
- Хост: `https://api.datagram.info/api/public/v1` (не `datagram.info/api/v1` из доки).

## Неподтверждённые возможности (уточнить у поддержки)

- AI Enricher и выбор канал/чат — нет в публичном API (только UI дашборда).
- Возврат токенов после завершения — не наблюдается.
